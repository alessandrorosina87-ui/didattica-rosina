Come Creare un Account e Pubblicare il Proprio Sito su free.nf

Durante le giornate di laboratorio abbiamo sviluppato pagine web interattive (HTML, CSS e JavaScript), come la Single-Page Application dell'Incontro 3. Per rendere questi progetti visibili a chiunque su Internet senza spendere un centesimo, utilizziamo il servizio di hosting gratuito https://free.nf/. Segui con attenzione i passaggi illustrati di seguito.

📸 Figura 1: Panoramica della creazione dell'Hosting Account su free.nf (Piano Gratuito a 0€, scelta dell'estensione di dominio, verifica disponibilità e pulsante verde finale).
1
Accesso alla Piattaforma

Registrazione oppure Login su free.nf

Apri il tuo browser preferito e collegati alla pagina web ufficiale del servizio: 🔗 https://free.nf/

  • Se è la prima volta che utilizzi la piattaforma, esegui la registrazione (Sign Up / Register) inserendo un indirizzo email valido e una password, confermando l'eventuale messaggio di verifica ricevuto nella casella di posta.
  • Se invece possiedi già le credenziali, clicca direttamente su Login per accedere alla tua area personale (Client Area Dashboard).
2
Dashboard Personale

Accesso alla Sezione "Hosting Account"

Una volta entrati nella schermata principale del proprio profilo, individuate nel pannello laterale o nella barra superiore il pulsante / voce di menu denominato:

Hosting Account (in alcune versioni compare come Accounts)

Cliccandoci sopra avrete la visualizzazione d'insieme di tutti i vostri spazi web attivi.

3
Nuovo Hosting

Cliccare su "Create Account" e Selezionare il Piano Gratuito a 0 €

Nella schermata degli account hosting:

  1. Fate clic sul pulsante Create Account (Crea Account).
  2. Nella tabella comparativa dei piani di hosting disponibili, individuate il piano gratuito a 0 euro (Free Plan / 0 €).
  3. Selezionate questo piano per confermare che non vi sarà alcun addebito o costo nascosto.
💡

Perché il Piano 0 € è ideale per la scuola

Fornisce 5 GB di spazio su disco, banda illimitata, supporto PHP e MySQL e certificato SSL HTTPS gratuito, perfetto per pubblicare tutti i siti e gli esperimenti del corso.

4
Configurazione Dominio

Inserire il Nome del Sito e Scegliere l'Estensione dal Menù a Tendina

Nella sezione Domain Name selezionate l'opzione Subdomain (sottodominio gratuito incluso):

  • Nel riquadro di testo inserite il nome che volete dare al vostro sito (ad esempio: progetto-scuola, didattica-ai-2026, laboratorio-rossi). Consigliamo di usare solo caratteri minuscoli, numeri e trattini, senza spazi né accenti.
  • Subito accanto, aprite il menù a tendina per selezionare l'estensione di dominio desiderata (ad esempio .free.nf, .infinityfreeapp.com, .epizy.com).
🧭

Il Criterio di Scelta Didattico

L'estensione può essere qualsiasi tra quelle proposte. In questo contesto didattico, la scelta si effettua unicamente in base al livello di facilità nel ricordarla, pronunciarla e dettarla ai colleghi o agli studenti (es. l'estensione .free.nf è particolarmente breve e immediata).

5
Controllo Unicità

Cliccare su "Check Available" per Verificare la Disponibilità

I domini web sono identificativi unici al mondo: due siti non possono avere esattamente lo stesso indirizzo.

Check Available (Verifica disponibilità nome)
  • Se il nome è disponibile: il portale mostrerà un messaggio di conferma verde e sbloccherà i campi successivi per la password.
  • Se il nome è già occupato: non preoccupatevi! Basterà provare ad aggiungere un numero, l'anno in corso (es. 2026) o selezionare una diversa estensione nel menù a tendina.
6
Credenziali & Consensi

Password di Gestione e Spunta su "I Approve" (Email Consent)

Per proteggere il vostro spazio di hosting e finalizzare la procedura:

  1. Hosting Account Password: inserite una password robusta per la gestione del nuovo spazio server (conservatela con cura nei vostri appunti).
  2. In corrispondenza della voce Email Consent, individuate la casella di controllo e mettete la spunta su: ☑ I Approve.
  3. Questo passaggio è obbligatorio per consentire al sistema di notificarvi l'attivazione e i parametri tecnici del servizio.
7
Provisioning Server

Invio del Modulo e Attesa del Caricamento

Premete il pulsante di invio (es. Create Account o Submit):

  • Il sistema vi reindirizzerà automaticamente in una nuova pagina di transizione.
  • In questo frangente i server di free.nf stanno creando la partizione su disco, allocando lo spazio web e configurando i record DNS.
  • Non ricaricare né chiudere la pagina: dovrete semplicemente aspettare pochi istanti fino al termine del caricamento automatico.
8
Conferma & Accesso

Clic sul Pulsante Verde: Accesso alle Impostazioni del Nuovo Dominio

Una volta completata l'attivazione in background:

Finish / Control Panel (Pulsante verde di conferma)

Apparirà un evidente pulsante verde sullo schermo: cliccateci sopra e sarete immediatamente reindirizzati nella schermata di gestione con tutte le impostazioni generali del vostro nuovo dominio (indirizzo IP del server, parametri FTP, stato attivo).

9
Caricamento File Web

Cliccare su "File Manager" e Inserire i File (Come su una Pen Drive)

Dalla schermata di configurazione del dominio:

  1. Individuate e cliccate sul pulsante: File Manager (in alcuni casi Online File Manager).
  2. Si aprirà l'interfaccia web per esplorare le cartelle del vostro spazio hosting.
  3. Entrate nella cartella principale pubblica del sito, denominata: htdocs.
  4. Ora inserite, esattamente come se steste copiando file all'interno di una normale pen drive USB, tutti i file che avete creato durante il corso:
    • index.html (la pagina principale del vostro sito web)
    • Gli altri file delle lezioni (es. giornata-1.html, guide.html, ecc.)
    • L'intera cartella assets/ contenente i fogli di stile (css/), gli script (js/) e le immagini (img/).

Potete caricare i file sia tramite il pulsante Upload del File Manager, sia trascinandoli (Drag & Drop) direttamente dalla finestra delle cartelle del vostro computer dentro l'interfaccia web del browser.

💾 Figura 2: Il File Manager online nella cartella htdocs. Il caricamento funziona esattamente come il salvataggio su una chiavetta USB: trascinando i file, il sito diventa immediatamente raggiungibile su Internet.
10
Sito Online!

Accesso ai Contenuti tramite l'Indirizzo Web

Una volta caricato tutto all'interno di htdocs, il vostro sito web è immediatamente online e accessibile da qualsiasi computer, smartphone o tablet nel mondo!

Per visualizzare i contenuti vi basterà aprire una nuova scheda del browser e digitare:

Sintassi degli Indirizzi Web di free.nf 
# Per aprire la Home Page (il file index.html viene aperto in automatico):
https://nomesito.estensione

# Per accedere direttamente a un file specifico o a una pagina:
https://nomesito.estensione/nome_file

# Esempi pratici:
https://scuola-ai.free.nf/
https://scuola-ai.free.nf/giornata-1.html
https://scuola-ai.free.nf/assets/img/hero.jpg
📌

Regola Fondamentale del Web

I server web cercano sempre come file iniziale predefinito quello che si chiama esattamente index.html (tutto minuscolo). Se chiamate la vostra pagina iniziale con un altro nome, dovrete necessariamente specificarlo per intero nell'URL dopo la barra finale (/).
